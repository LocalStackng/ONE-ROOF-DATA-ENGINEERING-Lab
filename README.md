# ONE-ROOF-DATA-ENGINEERING-Lab
ASSIGNMENT — WEEKEND OF 5–6 SEPTEMBER 2026    PRE-DATA LOAD ENGINEERING CHECKS
## This week assignment is about knowing more about your source data and running quality check queries.
Pre load checks help data engineers identify issues early and protect downstream data consumers.  
Some business questions where also answered from Data Engineering perspective.  
The assignment reinforced the principle that data should be understood and validated before it is loaded into a production or analytical environment.  
A very good way to start data engineering mentorship class.
